# Google Sheet Structure

## Sheet1
This sheet stores the main internship records.

- B: Student_ID
- C: Name
- D: Email
- E: Joining_Date
- F: Module
- G: Assigned_Task
- H: Task_Email_Status
- I: Review_Date
- J: Review_Time
- K: Submission_Link
- L: AI_Feedback
- M: Next_Review_Date
- N: Status

## Form_Responses
This sheet stores form submissions.

- A: Timestamp
- B: Student ID
- C: Email Address
- D: Task Name
- E: Submission Link

## Automation
Google Apps Script matches the student ID and email address, updates the submission link, generates predefined feedback, and sends an email.

## Privacy
Do not publish actual student personal information or private submission data.
