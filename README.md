# AI Internship Management System

## About the Project
This project automates internship task management using Google Sheets, Google Forms, Google Apps Script, and Gmail.

## Features
- Automatic task assignment emails
- Google Form submission collection
- Submission link tracking
- Rule-based feedback generation
- Automatic feedback emails

## Technologies Used
- Google Sheets
- Google Forms
- Google Apps Script
- Gmail
- JavaScript

## How It Works
1. Student details are stored in Google Sheets.
2. Task details are sent through email.
3. Students submit their work using Google Forms.
4. Submission links are saved in the spreadsheet.
5. Predefined feedback is generated and emailed.

## Project File
- Code.gs: Contains the Google Apps Script automation code.

## Note
Feedback is generated using predefined rules and is not an actual AI evaluation.

## Security
No passwords, API keys, or private student information should be published.
